{{/* Responsive screenshot with click-to-zoom, degrading twice. Three cases, because all three happen in a template-born project: 1. `assets/` exists — resize it and emit a srcset. Retina captures are 250-600KB and must not be shipped at full weight into a 600px slot. The format is left alone so the build works on any Hugo edition; if yours is the extended edition, appending `webp q88` to the Resize specs roughly halves these. 2. `static/` exists — emit a plain at its published URL. Hugo cannot process static files, so there is no srcset, but a real unoptimized screenshot beats a placeholder. Move the file into assets/ to get case 1. 3. Neither — render the dashed placeholder. This is the normal state of a freshly stamped project, so it must not fail the build.
